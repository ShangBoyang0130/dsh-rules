# 术语表

两边用同一批词。**出现新旧说法不一致、或某个词第一次登场时，读这份。**

分两组：第一组是这套体系里我们自造/约定的说法（agent 必须照着用）；
第二组是技术词（用户还在学的那些，agent 第一次用到时照这里的说法解释）。

**怎么维护这份表**：在手边那一组加一行；是 skill 的话，填上「对应 skill」列（中文短词 ↔ 它的英文 `name`）。
第二组是**会变短**的：学会一个就删一个 —— 只加不删会沉积（见下面「沉积」那条）。

---

## 一、这套体系里的固定说法

| 词 | 对应 skill | 一句话 |
|---|---|---|
| **工作区** | — | 指定给 dsh 读写的那个文件夹（启动 dsh 时定的，也是每次开工的落脚点）。**它里面怎么分**，见那一份 `AGENTS.md` |
| **规矩文件** | — | `AGENTS.md`。全局一份（所有会话都读）+ 工作区一份 |
| **归档区** | — | 以前做完的东西，按成品对待，不是待办。（叫什么名、放在哪，各工作区自己定） |
| **活跃** | — | 在用的东西，会增减。（同上：名字与位置由工作区自己定） |
| **线** | — | 工作区根下的**一个目录 = 一条互不相干的工作线**，那条线的全部在用件（代码 + 它自己的
  `AGENTS.md` + 它自己的 `交接.md`）都住里面。任务落在哪条线，就先读那条线的 `AGENTS.md` |
| **通用层** | — | **跨线共用**的那一小撮（工作区根 `AGENTS.md` · `AGENTS.local.md` · 活跃区里那几份跨线的
  常驻文件）。不落在任何线上的活（改规矩 / 发公开包 / 跨线整理）只读它 |
| **中转区** | — | 跨机往返用的中转目录（**每天跟着 U 盘剪走**）⇒ **不进任何台账**：不进交接的行数表、
  不进位置台账。登记了机检就会报「缺文件」 |
| **skill / 技能** | — | 按需加载的说明书，常驻的只有它的「描述」那一行 |
| **常驻 vs 按需加载** | — | 两种成本：每轮都花 vs 只在被调用时花 |
| **前置判据** | — | 放在描述最前面的一句「什么情况下才用我」 |
| **指针** | — | 上下文里指向某份不在上下文里的材料的引用；它的**措辞**决定什么时候被读到 |
| **标来源** | — | 结论后面标【实测】/【推断】/【猜测】 |
| **沉积** | — | 只加不删的默认下场：旧条款一层层沉下去，最后要钻穿才能找到还活着的 |
| **审查** | `agents-md-audit` | 用一轮检查项 + 交叉验证过一遍规矩文件（几条以那个 skill 里的清单为准） |
| **盘我** | `grill-me` | 让 agent 反过来一轮轮追问，直到没有默认假设 |
| **交接** | `handoff` | 把当前会话压成给下一个会话看的文档（**每轮覆盖的那一份**） |
| **重讲** | `wait-what` | 没听懂时喊停，让它带着缺的上下文重讲（走简化技术英语那一路） |
| **给AI写文档** | `writing-for-agents` | 改规矩文件或建 skill 之前先读的那份规则 |
| **路标** | — | 自动加载的那几行短索引（在工作区 `AGENTS.md` 里）：只回答「重材料在哪、什么条件下读」 |
| **常驻文件** | — | 活过对话、但不每轮自动加载的文件。长期口径**与**要干的活住这里；**每轮覆盖的那份**只住本轮状态 |
| **待办文件** | — | 要干的活的那一份：开工先读它、做完的条目删行 |
| **够用本金区间** | — | 「这条策略 + 这个盘」有一段本金区间：**低于下限你跑的其实是另一个组合**（建不满 / 每笔按最低费用收），**高于上限**收益被自己的冲击吃掉。下限 = 三个门槛（最小交易单位 / 固定费用 / 流动性）里**最紧的那个**；区间内越大越好（固定费用被摊薄），所以**没有「最优本金」这个点** |
| **被动保守** | — | **不是你有意加的过滤器**，而是机制静默改掉了持仓构成（本项目里最大的一条 = 整手 100 股，买不起就买 0 股）⇒ 它**必须有「放弃成本」数字**，不能当「没什么影响的实现细节」 |
| **同步机检** | — | 同一事实被复制成两处时，配的那个**机器可跑的比对**。判据是**它能抓住「两处真的不一样」** —— 只证「两处都没变」的不算（把产物重出一张表、再核同一批产物，属于后者） |
| **产物自证** | — | 产物自己说清「我是哪一趟跑的」：名字带**会变的口径键**（窗口 / 档 / 参数）＋时间戳或短哈希，内部再落一段自述（跑了哪条链、跳过了什么）。防的是「**读到的产物不是这一趟的**」—— 它不报错、看着还挺对 |

| **跳过 ≠ 通过** | — | 核过的与没核过的**分开数**：一次核完要印「核了 N 条 / 跳过 N 条」。
  **跳过 = 没核过**；把它混进「通过」里，报出来的就是「没验过」冒充「验过」。跳过进不进退出码
  **各工作区定死一个**、并写进那个工作区 |

## 二、技术词

| 词 | 一句话 |
|---|---|
| **路径 / 绝对路径 / 相对路径** | 文件在哪。绝对从盘符写起（`D:\x\y`），相对从当前目录算起 |
| **编码** | 文字在文件里怎么变成字节。常见三种：**UTF-8**（现在通用，dsh 只认它）、**GBK / ANSI 936**（中文 Windows 的老默认）、**UTF-16**。读错编码会乱码，或**行数凭空变少** |
| **BOM** | 文件开头那三个字节的标记。**PowerShell 5.1 读 `.ps1` 时必须有它** —— 否则文件里的中文被当 ANSI 解：轻则字符串静默变乱码，重则解析失败（今天实测踩过）。`.bat` 只要内容是纯 ASCII 就不受影响 |
| **LF / CRLF** | 换行用哪个字符。`LF` 是 `\n`，`CRLF` 是 `\r\n` |
| **缓存** | 存起来免得重算的结果。最常撞见的：**新建 skill 后 `/` 菜单不更新**，就是缓存没清，要重启服务 |
| **环境变量** | 系统级的设定值，任何程序都能读到。例：`%USERPROFILE%` 是用户文件夹、`PATH` 是系统去哪找命令 |
| **端口** | 一台机器上给不同服务用的门牌号。dsh 的网页在 `127.0.0.1:3080` —— 前半是「本机」，后半是门牌号 |
| **依赖** | 一个东西要用到的另一些东西。例：dsh 要跑起来得先有 Node.js，Node.js 就是它的依赖 |

# 这个工作区是什么

**做完的工作存 `存放\`；在用的东西按「线」住。** 这个工作区 = **若干条互不相干的线**（每条线一个目录）
＋ **一个跨线通用层**（`活跃\` 与本文件）。

`存放\` 里的东西只有用户点名时才去打开、修改或运行；在用的（线目录、`活跃\` 里通用层的东西）按各自的规矩走。

## 结构

| 位置 | 是什么 |
|---|---|
| `<线>\` | 一条线的全部在用的东西（代码 + 它自己的规矩 / 口径 / 交接）—— 见下面〈怎么找线〉 |
| `活跃\` | **跨线共用**的在用件（含义比字面窄：**不是**「所有在用的东西」） |
| `存放\` | 做完了的，按线 / 项目分目录 |
| `AGENTS.md` | 本文件 —— 规矩文件，会改 |
| `AGENTS.local.md` | （可选，自己建）本机 / 私有补充 —— **不进任何仓库**（DSH 会把同名 `.local` 覆盖层与 `AGENTS.md` 一起自动加载） |
| `_dsh-web.log` | （装了启动脚本、跑过一次之后才有）启动脚本生成的日志，每次启动覆盖重写，不用管 |


## 交接的硬检查（每轮交接都要满足）

1. **给「文件路径 + 行数」**：行数按**含空行**算（`@(Get-Content <路径> -Encoding UTF8).Count`）。这是不依赖
   AI 自述的检查。
2. **上一轮列的每一项都要有结局**（做完 / 没做完 / 放弃并说明 / 转到别处）：允许出现新事项，
   不允许旧的没有结局。
3. **写哪一份**：本轮在哪条线上 → 写那条线的 `交接.md`；通用线（改规矩 / 发公开包 / 跨线整理）→ 写 `活跃\交接.md`。
   **判断不了本轮属哪条线就问一句**（宁可问，别写错那份）。

## 怎么找线

**每条线 = 工作区根下的一个目录**，装那条线的全部在用的东西，外加一份 `AGENTS.md`（它自己的规矩）。
**任务落在哪条线，就先读那条线的 `AGENTS.md`**；不落在任何线上（改规矩 / 发公开包 / 跨线整理）只读通用层。


- **通用层**（跨线共用）：本文件 · `AGENTS.local.md` · `活跃\` 里那几份跨线的常驻文件（怎么干活 / 这台机器的脾气 /
  规矩改动队列 / 发公开包）· 规矩与 skill 的源
- **跨项目合作规矩**（人称 / 权限 / 备份 / 推理等级 / 证据纪律）在 `~/.dsh/AGENTS.md`，每轮自动加载、不用主动读
- ⚠️ **工作目录一律 = 工作区根**。**为什么**：DSH 按「项目根 → 工作目录」逐层加载 `AGENTS.md`，
  而项目根靠**向上找 `.git`** 认 —— 工作区没有 `.git` 时，工作目录一落进子目录，项目根就变成那个子目录、
  **本文件不会被加载**（通用规矩会丢）。⇐ 所以**每条线那份 `AGENTS.md` 第一行必须指回本文件**
- ⚠️ **带当事人 / 客户 / 案件材料的线**：那些材料只住那条线的目录 —— **不进公开包、不进通用层、不当任何文件的举例**

# 这个工作区是什么

**做完的工作存这儿（`存放\`），在用的东西放 `活跃\`。** 放这儿图个方便，一律按成品对待。

`存放\` 里的东西只有用户点名时才去打开、修改或运行；在用的（`活跃\`、本文件指到的路径）按各自的规矩走。

## 结构

| 位置 | 是什么 |
|---|---|
| `活跃\` | 在用的东西，会增减 |
| `存放\` | 以前做完的工作，纯存放 |
| `AGENTS.md` | 本文件 —— 规矩文件，会改 |
| `AGENTS.local.md` | 本机 / 私有补充 —— **不进任何仓库**（DSH 会把同名 `.local` 覆盖层与 `AGENTS.md` 一起自动加载） |
| `_dsh-web.log` | 启动脚本生成的日志，每次启动覆盖重写，不用管 |


## 交接的硬检查（每轮交接都要满足）

1. **给「文件路径 + 行数」**：行数按**含空行**算（`@(Get-Content <路径> -Encoding UTF8).Count`）。这是不依赖
   AI 自述的检查。
2. **上一轮列的每一项都要有结局**（做完 / 没做完 / 放弃并说明 / 转到别处）：允许出现新事项，
   不允许旧的没有结局。

## 路标：做什么读什么

- **跨项目合作规矩**（人称 / 权限 / 备份 / 推理等级 / 证据纪律）在 `~/.dsh/AGENTS.md` ——
  那份每轮自动加载，不用主动读

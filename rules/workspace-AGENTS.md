# 这个工作区是什么

**这里只存放已经做完的工作。** 放这儿图个方便，一律按成品对待。

只有我明确点名某个文件时，才去打开、修改或运行它们。

## 结构

| 位置 | 是什么 |
|---|---|
| `活跃\` | 在用的东西，会增减 |
| `存放\` | 以前做完的工作，纯存放 |
| `AGENTS.md` | 本文件 —— 规矩文件，会改 |
| `_dsh-web.log` | 启动脚本生成的日志，每次启动覆盖重写，不用管 |

## 有个文件容易被误读

`存放\先看这里.md` 是我当时写给自己的笔记。里面「明天早上唯一要做的事」那一段
是**当时**的待办，早就过期了。

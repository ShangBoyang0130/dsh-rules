# 给 agent 写文档

目标一句话：**让文档每轮花得少、触发得准、不会烂掉。**

（本 skill 自己是 model-invoked 的样板：写文档时 agent 必须自己想到来调它，所以它值得付一行常驻 description。）

## 一、先定 invocation —— 它决定后面一切

判定只有一句：只有 **agent 必须自己够到它**、或 **别的 skill 必须够到它** 时，才做成
model-invoked。只在手动触发时才用 → 做成 user-invoked。

| | model-invoked（默认） | user-invoked |
|---|---|---|
| 怎么设 | 省略 `disable-model-invocation` | 加 `disable-model-invocation: true` |
| description 面向 | **模型**：保留触发分支 | **用户**：一句话摘要，去掉触发列表 |
| `whenToUse` | 写（模型字段） | **不写**（此时它什么都不做） |
| 每轮上下文成本 | 1 行（description 常驻） | **0** |
| 谁能触发 | 模型 + 用户 | **只有用户**，走 `/` 菜单 |
| 别的 skill 能调用吗 | 能 | **永远不能** |

【实测】加上 `disable-model-invocation: true` 之后，skill 当场从模型目录消失，但仍留在 `/`
菜单里（带「仅限用户」标记）。**`/` 菜单本身就是 router** —— user-invoked skill 再多，也不需要
另做一个 router skill。

## 二、description 就是「指针」

指针 = 上下文里的一条引用，它命名某份不在上下文里的材料，并编码了什么条件下该去取它。

- **措辞决定触发，不是目标决定触发。** 措辞弱的指针 = 方差 bug：先磨措辞，磨不动才把内容内联
- 一个**分支**一条；同义词是同一个分支写了两遍 —— 合并
- 常驻的每个字都在每轮花钱 → **指针比正文更该狠砍**
- **开头那几个字在干触发活**，把最强的词放最前面
- 指针里重复正文已有的内容 = 白花负载

## 三、硬约束（dsh 实测，照抄即可）

| 项 | 规则 |
|---|---|
| 文件名 | **必须叫 `SKILL.md`**。改了 skill 会彻底消失，而且不报错 |
| 文件夹名 | **自由**，中文也行 —— 身份来自 frontmatter 的 `name`，不是文件夹 |
| `name` | 必须 kebab-case（小写字母/数字/连字符），否则整个 skill 被跳过 |
| 可用的键 | 只有 `name`、`description`、`whenToUse`、`disable-model-invocation`、`user-invocable`、`metadata`。别的工具家的键（如 `argument-hint`）写了不生效 |
| 放哪 | `~/.dsh/skills/<随便什么文件夹名>/SKILL.md` —— dsh 专用的放这儿；想给别的 agent 工具共用的，放 `~/.agents/skills/`（两个根都会被扫） |
| 新建后多久可见 | 模型目录**当场**生效；**`/` 菜单要重启 dsh 服务**才看得到（进程级收集缓存按 preset 作用域存，同 preset 的所有会话共用一条 —— **开新会话和刷新页面都没用**）|
| 什么会被自动读 | 只有 `AGENTS.md`（`~/.dsh/` 一份 + 工作区一份）。**skill 正文只在被调用时才进上下文** |

## 四、长度：优先砍，往「披露」推

信息分三层：**正文步骤 → 正文参考 → 披露出去的参考**（推到旁边的文件，用指针引）。

- **分支测试**：每个分支都要的写正文；只有某些分支需要的，推到指针后面
- **沉积**是默认下场：加了觉得安全、删了觉得可惜，最后要钻穿才能找到还活着的那些
- **优先砍，不优先加。** 一条修改让文档变长、却没换来可判定性，先怀疑它值不值
- 一份**纯参考**的文档（全是规则、没有步骤）是正常形态，不是缺陷

## 五、判断该删哪条：no-op 测试

问：**这条相对模型的默认行为，改变了什么？**
没改变 = no-op，白花负载。**整句删掉，不要只删几个词。**

有分歧时：**跑一遍**解决，不靠辩论 —— 争的其实是各自心里的「默认」假设。

## 六、写法：说正面目标

用「不要…」「别…」来引导，会把被禁的行为**拉进上下文**，反而让它更可得（「别想大象」）。
说出**要做什么**。禁令只留给无法正面表达的硬护栏（例如「`SKILL.md` 文件名固定」），
而且最好配一句正面目标。

## 七、交稿之前：三项自检（完成标准）

改完任何一份这类文档，**逐项做完再交**：

1. **重读指代** —— 「我」= 用户，指 AI 就写「AI」，全文不出现「你」。
   **新加或改写一句之后，回头重读「它 / 该文件 / 该 skill」这类回指有没有变歧义。**
2. **逐条过 no-op** —— 每条相对默认行为改变了什么？
3. **报长度变化** —— 这一版比上一版长/短了多少（**给实测数字，不给预估**）。

# 把探索外包给子会话

目标一句话：**把「读了多少材料」和「谁做判断」分开** —— 材料堆在子会话那边，
主会话留出上下文用来判断、拍板、拼接结论。

## 一、先认一件事：外包的是探索，不是判断

子会话是**新对话**：看不到本会话任何一句。它擅长的是一次性的、有界的、能自证的活。

| 外包（好） | 不外包（把判断推出去了） |
|---|---|
| 大范围搜 / 跨文件读 / 逐条核 | 拍板：做不做、选哪条路、改哪个口径 |
| 独立复现一遍、独立审计一份产物 | 「帮我看看接下来该干什么」 |
| 联网调研一批事实 | 顺手改仓库里任何文件 |

## 二、分派单要自足 + 有界（最容易翻车的一步）

**先侦察再外包**：不摸一遍就写出来的分派单，是在猜。自己花一两条命令看目录、抽样读两三个文件，
认出「这是什么材料、哪几份值得细看」，再写单。**侦察是取证，不是探索** —— 它进的是主会话，很便宜。

分派单里必须有：

1. **要读什么**：具体路径（绝对路径最好）；材料有一份清单时，把清单也给它
2. **要回答什么**：一句话 —— 子会话要靠这句自己纠偏
3. **交回什么形状**：逐条列、每条带来源（文件路径 + 行号 / 命令 / 数字）；
   结论写进文件再只回路径（长内容别往回复里倒）
4. **别碰什么**：不改任何文件（除非明说）；拿不准的标【推断】/【猜测】
5. **它这一轮的边界**：换台机 / 会不会被沙箱拦住 / 能不能联网 —— 它撞上会自己绕路，
   绕出来的路不一定是你要的；撞到权限就该**原样上报**，不是在子会话里自行想办法

**点名要缺口**：末尾直接要「你查不到的、你没验的、你跳过的」三项。不点名要，它们不会出现，
而它们比结论值钱 —— 不然「没查到」会被静默改写成一个看起来很完整的结论。

## 三、回来之后：按验收四条走

**怎么验收在全局 `~/.dsh/AGENTS.md` 的「子 agent 的交付怎么验收」那一节**，四条在那儿写全了；
本 skill 不另立一套。

配套的两条动作：**原样留下它的发现**（别在主会话里只复述自己的总结，否则第 ① 条没法执行）；
四条里第 ③④ 条要求的是「**这一轮没人能查的**」「**从头到尾没人碰过的检查项**」，
子会话说「做不到」时，正确处置是**原样上报给用户**。

## 四、什么时候别外包（照实说）

- **顺手就能读的**：一个文件、一条命令的答案 —— 外包的往返比直接读贵
- **要用户拍板的**：那件事本来就不该由子会话或 AI 定
- **需要读完全文再判断的**：材料的**每一句**都影响判断时，中间隔一层摘要就是丢证据
- **要改文件的活**：子会话与主会话同写一个工作区会互相盖；要写就串行，或只让一个写
- **一处结论撑着整段**：关键判断自己复现一遍 —— 子会话可能错，而且它的错也会写得很像真的
